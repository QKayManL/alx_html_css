# 🎧 Headphones Website – ALX HTML & CSS Project

This project is a pixel-perfect implementation of a Figma design for a fictional Headphones company.  
The goal is to translate the given UI design into clean, responsive HTML and CSS while practicing layout, typography, spacing, and component styling.

This project also strengthens Figma interpretation skills — understanding frames, constraints, spacing values, and responsive variations.

---

## 🟨 Figma Design Reference
The full UI design is available in the provided Figma project.  
Be sure to **Duplicate to your Drafts** in Figma to inspect fonts, spacing, and components.

If fonts are missing, download them here:
- **Source Sans Pro**
- **Spin Cycle OT**

---

## 📱 Responsive Behavior
- The layout switches to **mobile view** when the screen width is **480px or less**.
- Design elements scale cleanly and remain readable on smaller screens.

---

## 🎛 Interactions & Styling Notes

### 🚩 Link Hover & Active State
- Change link color to **#FF6565**

### 🔘 Button Hover & Active State
- Use **opacity: 0.9**

### 📏 Layout Constraint
- Max content width: **1000px**, centered on the page
